# ແອັບປະເມີນ KPI ພະນັກງານ

ແອັບໃນໂທລະສັບ ສຳລັບປະເມີນ KPI ຕາມຄູ່ມື ຂອງ ກຸ່ມບໍລິສັດ ລາວໃຕ້: ຫົວໜ້າຖືກປະເມີນ 4 ຟອມ, ພະນັກງານອື່ນ 3 ຟອມ. ແອັບຄິດໄລ່ຄະແນນ ແລະ ລະດັບ A–E ໃຫ້ເອງ.

- ໜ້າເວັບ: `dist/index.html` (ໄຟລ໌ດຽວ, ວາງເທິງ GitHub Pages)
- ບ່ອນເກັບຂໍ້ມູນ: Google Sheet + Apps Script (`dist/Code.gs`)
- ລອງໃຊ້ກ່ອນໄດ້ໂດຍບໍ່ຕ້ອງມີ Google: ເປີດ `dist/index.html` → "ເປີດໂໝດທົດລອງ"

## ຕັ້ງລະບົບແທ້ (ເຮັດຄັ້ງດຽວ, ~15 ນາທີ)

1. **ສ້າງ Google Sheet ໃໝ່** ໃນ Google Drive ຂອງບໍລິສັດ (ຕັ້ງຊື່ເຊັ່ນ "KPI 2026"). **ຢ່າແບ່ງປັນ** ໃຫ້ໃຜ ນອກຈາກ HR.
2. ໃນ Sheet: ເມນູ **Extensions › Apps Script**.
3. ລຶບໂຄ້ດເກົ່າໃນ `Code.gs` ອອກ, **ວາງເນື້ອໃນທັງໝົດຂອງ `dist/Code.gs`** ແທນ, ກົດ 💾 ບັນທຶກ.
4. ເລືອກຟັງຊັນ **`setup`** ຢູ່ແຖບເທິງ → ກົດ **Run** → ອະນຸຍາດສິດ (Review permissions → ເລືອກບັນຊີ → Allow).
5. ເປີດ **Execution log** ຈະເຫັນ: `ບັນຊີ HR ທຳອິດ: ລະຫັດ HR001  PIN xxxxxx` — **ຈົດໄວ້**.
6. ກົດ **Deploy › New deployment** → ປະເພດ **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   → Deploy → ກັອບປີ້ **Web app URL** (ລົງທ້າຍດ້ວຍ `/exec`).
7. ເປີດໜ້າເວັບ, ວາງ URL ໃນ "ເຊື່ອມຕໍ່ລະບົບຂອງບໍລິສັດ" — ຫຼື ສົ່ງລິ້ງນີ້ໃຫ້ພະນັກງານ (ເປີດແລ້ວເຊື່ອມຕໍ່ເອງ):
   `https://<ລິ້ງ GitHub Pages>/?api=<Web app URL>`
8. ເຂົ້າລະບົບດ້ວຍ `HR001` + PIN ຈາກຂໍ້ 5.

## ເລີ່ມຮອບປະເມີນ (HR)

1. **HR › ພະນັກງານ › ນຳເຂົ້າຈາກ Excel**: ກັອບປີ້ຖັນ `ລະຫັດ · ຊື່ · ພະແນກ · ຝ່າຍ · ຕຳແໜ່ງ · ກຸ່ມ KPI · ລະຫັດຫົວໜ້າ · ລະຫັດຜູ້ອະນຸມັດ · ບົດບາດ` ແລ້ວວາງ. ໃສ່ບົດບາດ `PRESIDENT` ໃຫ້ປະທານ ແລະ `HR` ໃຫ້ພະນັກງານ HR ຕົວຈິງ.
2. **ສ້າງ PIN ໃຫ້ທັງໝົດ** → ພິມລາຍການ PIN ແຈກໃຫ້ແຕ່ລະຄົນ (ສະແດງຄັ້ງດຽວ).
3. ຫົວໜ້າ ຕັ້ງ KPI ດ້ານ I ໃຫ້ລູກນ້ອງ → ພະນັກງານຮັບຮູ້ → HR ກວດ → ຜູ້ອະນຸມັດ → ປະທານ.
4. **HR › ເພື່ອນຮ່ວມງານ › ແນະນຳອັດຕະໂນມັດ** (ແກ້ໄຂແຕ່ລະຄົນໄດ້).
5. **HR › ຮອບປະເມີນ › ເປີດໃຫ້ປະເມີນ** → ທຸກຄົນກອກຟອມໃນໂທລະສັບ. ຕິດຕາມໃນ **ຄວາມຄືບໜ້າ** (ມີລາຍຊື່ຜູ້ທີ່ຍັງຄ້າງ).
6. **ປິດຮອບ** → ກວດຜົນ / ດາວໂຫຼດ CSV → **ປະກາດຜົນ**.

ພາຍຫຼັງ ຖ້າອັບເດດໂຄ້ດ: ວາງ `Code.gs` ໃໝ່ → **Deploy › Manage deployments › ✏️ › Version: New version → Deploy** (URL ຄືເກົ່າ).

## ສິດ ແລະ ໜ້າທີ່ (Admin)

**HR › ສິດ ແລະ ໜ້າທີ່**: ສ້າງບົດບາດ, ຕິກເລືອກສິດ, ຕິກເລືອກຄົນ → ບັນທຶກ → ມີຜົນທັນທີ (ຄົນນັ້ນເຫັນເມນູໃໝ່ ເມື່ອເປີດແອັບຄືນ).

- ບົດບາດເລີ່ມຕົ້ນ: **ADMIN** (ທຸກສິດ, ແກ້/ລຶບບໍ່ໄດ້), **HR** (ທຸກສິດ ຍົກເວັ້ນ ກຳນົດສິດ ແລະ ອະນຸມັດສຸດທ້າຍ), **PRESIDENT** (ອະນຸມັດ KPI ສຸດທ້າຍ)
- ສິດທີ່ເລືອກໄດ້ 9 ຢ່າງ: ຈັດການພະນັກງານ/PIN · ກຳນົດສິດ · ຈັດການຮອບ · ກຳນົດເພື່ອນ · ຕັ້ງຄ່າ · ກວດ KPI (ຂັ້ນ HR) · ອະນຸມັດ KPI ສຸດທ້າຍ · ເບິ່ງຄວາມຄືບໜ້າ · ເບິ່ງຜົນທຸກຄົນ
- ໜ້າທີ່ປະເມີນ (ຫົວໜ້າ, ຜູ້ອະນຸມັດ, ເພື່ອນ) ຍັງກຳນົດໃນໜ້າ "ພະນັກງານ" ແລະ "ເພື່ອນຮ່ວມງານ" ຄືເກົ່າ
- ການປ້ອງກັນ: ປ່ຽນບົດບາດຂອງຄົນ ຕ້ອງມີສິດ "ກຳນົດສິດ"; ຕ້ອງມີຢ່າງໜ້ອຍ 1 ຄົນທີ່ໃຊ້ງານຢູ່ ທີ່ມີສິດ Admin ຫຼື ຈັດການພະນັກງານ. ຖ້າຍັງບໍ່ມີໃຜເປັນ ADMIN, ຄົນທີ່ມີສິດຈັດການພະນັກງານ (ເຊັ່ນ HR001) ໄດ້ສິດກຳນົດສິດໄປກ່ອນ
- ຂໍ້ມູນບົດບາດ ເກັບໃນ tab "ສິດ" ຂອງ Google Sheet

## ຂໍ້ຄວນຮູ້

- ຄະແນນຟອມ ③ ④ ລາຍຄົນ ບໍ່ສະແດງໃຫ້ຜູ້ຖືກປະເມີນ ຫຼື ຫົວໜ້າເຫັນ; **ແຕ່ຄົນທີ່ເປີດ Google Sheet ໄດ້ ເຫັນ** (tab "ຄຳຕອບ").
- ຢ່າແກ້ຂໍ້ມູນໃນ Sheet ໂດຍກົງ ຕອນມີຄົນກຳລັງໃຊ້ — ໃຊ້ໜ້າ HR ໃນແອັບ.
- ຖ້າພະນັກງານລືມ PIN: HR › ພະນັກງານ › ເລືອກຄົນ › ຕັ້ງ PIN ໃໝ່.

## ສຳລັບຜູ້ພັດທະນາ

```
node build.js                 # src/ → dist/index.html + dist/Code.gs
node tests/scoring.test.js    # ສູດຄິດໄລ່ (ຕົວຢ່າງຄູ່ມື 85.6 → B, ຂອບເຂດລະດັບ)
node tests/server.test.js     # ສິດ, ຂັ້ນຕອນອະນຸມັດ, ການປິດຊື່, ກົດຊ້ຳ
node tests/gas-smoke.test.js  # ແລ່ນ dist/Code.gs ກັບ Google Sheets ຈຳລອງ
```

ກົດລະບຽບ ແລະ ສິດທັງໝົດຢູ່ `src/server.js` (ໃຊ້ຮ່ວມ: Apps Script, ໂໝດທົດລອງ, tests). ອອກແບບ: `docs/2026-11-05-kpi-app-design.md`.
